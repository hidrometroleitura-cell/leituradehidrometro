========================================================================
COMO COLOCAR O PORTAL DO SINDICO ONLINE EM 10 SEGUNDOS (100% GRATIS)
========================================================================

Opcao 1: Netlify Drop (Mais Facil - Sem precisar instalar nada)
1. Acesse no seu navegador: https://app.netlify.com/drop
2. Arraste esta pasta 'portal-sindico' inteira para dentro do site.
3. O site vai gerar um link online na hora (ex: https://kr2melo-sindico.netlify.app).
4. No KR2MELO Dashboard, clique em 'Link do Sindico', cole esse link no campo
   'Endereco Publico do Portal Online' e clique em 'Salvar URL'.
5. Pronto! Todos os links de WhatsApp enviados para os sindicos usarao esse
   endereco publico e abrirao direto no celular de qualquer sindico!

------------------------------------------------------------------------
Opcao 2: GitHub Pages (Gratuito e Permanente)
1. Crie um repositorio publico no seu GitHub (ex: portal-sindico).
2. Faca o upload dos arquivos desta pasta.
3. Va em Settings -> Pages e ative a publicacao na branch 'main'.
4. Cole o link do GitHub Pages no KR2MELO Dashboard.
